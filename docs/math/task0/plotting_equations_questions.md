# Part A — Multiple Choice

Write the question number and the letter of the correct option.

**A1.** To plot the point (2, 5), starting from the origin you walk:

- A. 5 steps right, then 2 up
- B. 2 steps right, then 5 up
- C. 2 steps up, then 5 right
- D. 5 steps up, then 2 right

**A2.** Which point is on the picture of y = x + 2?

- A. (1, 2)
- B. (2, 1)
- C. (1, 3)
- D. (3, 1)

**A3.** The picture of y = 7 is:

- A. a vertical line
- B. a horizontal line
- C. an uphill line through the origin
- D. a U-shaped curve

**A4.** The picture of x = −3 is:

- A. a horizontal line below the x-axis
- B. a single point
- C. a vertical line left of the y-axis
- D. a downhill line

**A5.** Which rule draws a **straight line**?

- A. y = x × x
- B. x = y × y
- C. y = 5x + 1
- D. y = x × x + 3

**A6.** Which rule does **not** draw a straight line?

- A. y = x + 9
- B. x + y = 12
- C. y = x × x + 2
- D. x = 4y

**A7.** For the rule y = 2x + 3, when x = 4, y is:

- A. 9
- B. 10
- C. 11
- D. 14

**A8.** Which point is on the picture of x + y = 9?

- A. (4, 5)
- B. (5, 5)
- C. (9, 1)
- D. (3, 7)

**A9.** The lines y = 3 and x = 5 cross at:

- A. (3, 5)
- B. (5, 3)
- C. (0, 0)
- D. they never cross

**A10.** On the line of y = 3x + 1, one step right needs how many steps up?

- A. 1
- B. 2
- C. 3
- D. 4

**A11.** For the rule x = 3y + 2, feeding y = 3 gives which point?

- A. (3, 11)
- B. (11, 3)
- C. (9, 3)
- D. (3, 9)

**A12.** For the rule y = x × x, when x = −4, y is:

- A. −16
- B. 16
- C. −8
- D. 8

**A13.** Which point is on **both** pictures, y = x and y = x × x?

- A. (2, 2)
- B. (3, 9)
- C. (1, 1)
- D. (4, 2)

**A14.** The address of the origin is:

- A. (0, 0)
- B. (1, 1)
- C. (0, 1)
- D. (1, 0)
